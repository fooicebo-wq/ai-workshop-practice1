# 需求問卷 → Google 試算表 自動收件設定教學

整理日期：2026-10-07
來源說明：搭配 `需求問卷.html` 與本資料夾的 `Code.gs` 使用

客戶送出問卷後，資料會自動新增一列到 Google 試算表，風格照片存到 Google 雲端硬碟，試算表裡放照片連結。也可以設定成每收到一份就寄通知信。

---

## 一、建立試算表與收件程式（約 5 分鐘）

| # | 步驟 | 說明 |
|---|---|---|
| 1 | 開新試算表 | 到 [sheets.new](https://sheets.new) 建立空白試算表，命名如「集思需求問卷回覆」 |
| 2 | 打開 Apps Script | 選單「擴充功能」→「Apps Script」 |
| 3 | 貼上程式 | 刪掉編輯器裡原本的內容，把 `Code.gs` 全部貼上，按 💾 儲存 |
| 4 | （選用）設定通知信 | 把第 8 行 `NOTIFY_EMAIL = ''` 改成你的信箱，例：`'fooicebo@gmail.com'` |
| 5 | 授權並測試 | 上方函式選單選 `testWrite` → 按「執行」→ 依畫面完成 Google 授權（出現「Google 尚未驗證這個應用程式」時，按「進階」→「前往（不安全）」，這是你自己的程式，可放心） |
| 6 | 確認測試資料 | 回到試算表，應出現「問卷回覆」分頁和一列測試資料，確認後可刪掉該列 |

## 二、部署成網址

| # | 步驟 | 說明 |
|---|---|---|
| 1 | 部署 | 右上角「部署」→「新增部署作業」 |
| 2 | 類型 | 點齒輪 ⚙ → 選「網頁應用程式」 |
| 3 | 執行身分 | 選「**我**」 |
| 4 | 誰可以存取 | 選「**所有人**」（客戶不用登入 Google 才能送出） |
| 5 | 複製網址 | 按「部署」，複製「網頁應用程式網址」（`https://script.google.com/macros/s/.../exec`） |
| 6 | 檢查 | 用瀏覽器打開該網址，看到 `問卷收件程式運作中` 表示成功 |

## 三、把網址填入問卷

用記事本或 VS Code 打開 `需求問卷.html`，搜尋 `SUBMIT_URL`，填入剛剛的網址：

```js
const SUBMIT_URL = "https://script.google.com/macros/s/xxxxxxxx/exec";
```

存檔後打開問卷實際填一份，確認試算表有新增資料就完成了。

## 試算表欄位

`填寫時間｜姓名｜手機｜LINE ID｜地址｜社區｜屋齡｜房屋類型｜權狀坪數｜室內實坪｜裝修範圍｜局部空間｜交屋日｜希望入住日｜客變｜預算｜居住人數｜成員年齡｜寵物｜未來5年變化｜家庭變化補充｜喜歡風格｜風格照片｜參考連結｜不喜歡的元素｜主要決策者｜比較其他公司｜來源｜來源補充｜其他備註`

- 照片存在雲端硬碟「集思需求問卷_風格照片」資料夾，檔名為「姓名_日期時間_序號.jpg」
- 照片會先在客戶手機上縮小（長邊 1280px），上傳較快

## 注意事項

- **修改 `Code.gs` 後要重新部署才會生效**：「部署」→「管理部署作業」→ ✏ 編輯 → 版本選「新版本」→ 部署（網址不變）
- 若送出失敗（例如網路不穩），問卷會提示客戶「複製填寫內容」改用 LINE 傳送，資料不會遺失
- 問卷網址要給客戶使用，仍需把 `需求問卷.html` 放上網（例如 Vercel、GitHub Pages）
