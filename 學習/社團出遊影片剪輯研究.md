## 1. 社團出遊影片的特色

與個人旅遊 Vlog 不同，社團影片的觀眾是「參加的人自己」與「沒去的社員」，重點是**每個人都有出現、氣氛熱鬧、能勾起回憶**。

| 面向 | 個人旅遊 Vlog | 社團出遊回顧 |
|---|---|---|
| 主角 | 拍攝者自己 | 全體成員（人人都要入鏡） |
| 敘事 | 心得、旁白 | 時間順序＋情緒高潮，幾乎不用旁白 |
| 素材 | 自己拍的影片為主 | 多人手機的**照片＋短影片混剪** |
| 音樂 | 氛圍型 | 輕快、可卡點的流行歌或熱血曲 |
| 必備段落 | 景點介紹 | 大合照、團康遊戲、吃飯、NG 花絮、感謝名單 |
| 長度 | 5–15 分鐘 | 主版 3–5 分鐘；社群短版 30–60 秒 |

## 2. 影片結構範本

以 4 分鐘主版為例（約一首歌長度）：

| # | 段落 | 時間 | 內容 | 剪法 |
|---|---|---|---|---|
| 1 | 開場 Hook | 0:00–0:10 | 最精彩 3–5 個鏡頭快閃（歡呼、跳躍、風景） | 0.5–1 秒短切，卡重拍 |
| 2 | 片名 | 0:10–0:15 | 「2026 ○○社 秋季出遊｜地點｜日期」 | 大合照或風景當底圖，字卡淡入 |
| 3 | 出發 | 0:15–0:40 | 集合、上車、車上合照、點心 | 中等節奏，照片 2–3 秒 |
| 4 | Day 1 行程 | 0:40–1:40 | 依景點分段，每段先放「地點小字卡」 | 遠景 → 中景 → 特寫交替 |
| 5 | 晚會／團康 | 1:40–2:30 | 遊戲、表演、笑聲（保留原音） | 降低音樂、拉高現場聲 |
| 6 | Day 2 行程 | 2:30–3:10 | 同 Day 1 | 可略快 |
| 7 | 情緒高潮 | 3:10–3:40 | 大合照、夕陽、擁抱、慢動作 | 歌曲副歌，慢節奏、長轉場 |
| 8 | NG 花絮 | 3:40–3:55 | 搞笑、跌倒、鬼臉 | 快剪、可加音效 |
| 9 | 結尾 | 3:55–4:10 | 全體合照定格＋感謝名單（工作人員、攝影） | 音樂淡出 2 秒 |

**原則**：先有清楚的開頭、中段、結尾，前 3 秒就要抓住注意力，多餘的片段一律剪掉。

## 3. 素材整理與拍攝清單

### 整理步驟

| # | 工作 | 說明 |
|---|---|---|
| 1 | 收集 | 建共用雲端資料夾，請大家上傳**原檔**（LINE 傳會被壓縮） |
| 2 | 分類 | 依「天數／景點」分子資料夾，例：`D1_01集合`、`D1_02景點A` |
| 3 | 排序 | 依拍攝時間（EXIF）排序，多支手機的照片才不會亂序 |
| 4 | 挑選 | 每個景點挑 5–10 張最佳；同一畫面連拍只留 1 張 |
| 5 | 檢查人數 | 對照名單，確認每位成員至少出現 1–2 次 |

### 拍攝清單（出發前發給攝影組）

| 鏡頭類型 | 例子 | 用途 |
|---|---|---|
| 遠景 | 景點全景、遊覽車停車場 | 交代地點 |
| 中景 | 一群人走路、吃飯、玩遊戲 | 主要內容 |
| 特寫 | 笑臉、食物、手勢、名牌 | 情緒與細節 |
| 動態短片 | 跳躍、歡呼、乾杯（5–10 秒） | 開場 Hook、卡點 |
| 大合照 | 每個景點至少 1 張 | 片名、結尾 |
| 空景 | 天空、路牌、車窗外 | 轉場、放字卡 |

## 4. 節奏與卡點

| 段落 | 每個鏡頭長度 | 備註 |
|---|---|---|
| 開場快閃／花絮 | 0.5–1 秒 | 每拍一切 |
| 一般行程 | 照片 2–3 秒、影片 3–5 秒 | 每 2 或 4 拍一切 |
| 高潮／感性段 | 4–6 秒 | 慢轉場，可放慢動作 |

- **卡點**：切點、轉場對齊音樂的拍點，是這類影片最重要的技巧。
- **快慢交替**：快剪一段後接一段慢的，觀眾才不會疲乏。
- **照片要動起來**：靜態照片一律加 Ken Burns（緩慢放大或平移），否則像投影片。
- 自動卡點做法：用音訊分析抓出拍點時間（librosa 的 `beat_track`，或 aubio 的 onset 偵測），再依拍點分配每個鏡頭的長度。開源工具 kburns-slideshow 就是用 aubio 讓換片對齊音樂。

## 5. 轉場、字卡、配樂

### 轉場

| 情境 | 建議 | FFmpeg `xfade` 名稱 |
|---|---|---|
| 大部分切換 | 直接切（最乾淨） | 不用 xfade |
| 同一景點內 | 交叉淡化 0.3–0.5 秒 | `fade` |
| 換景點／換天 | 推移、滑入 | `slideleft`、`smoothleft` |
| 開場、結尾 | 圓形展開、淡黑 | `circleopen`、`fadeblack` |

轉場**不要太多種**，全片 2–3 種就夠，不然會顯得雜亂。

### 字卡

| 類型 | 內容 | 位置／時長 |
|---|---|---|
| 片名 | 社團名稱＋活動名稱＋日期 | 畫面中下，2–3 秒，淡入 |
| 地點 | 「Day 1｜日月潭」 | 左下角小字，2 秒 |
| 人物 | 幹部或表演者名字 | 下方三分之一處 |
| 感謝名單 | 主辦、攝影、贊助 | 片尾，捲動或分頁 |

字型用粗黑體＋白字黑邊，手機上才看得清楚。

### 配樂

| 原則 | 說明 |
|---|---|
| 1–2 首歌 | 前段輕快、高潮段換感性，長度剛好蓋住影片 |
| 版權 | 公開上傳（YouTube、FB）要用免版稅音樂（YouTube 音效庫等），或確認授權 |
| 音量 | 音樂約 -14 LUFS；有對話、笑聲的片段把音樂壓低（ducking） |
| 淡入淡出 | 開頭淡入 1 秒、結尾淡出 2 秒 |

## 6. FFmpeg 實作流程（已實測）

以下指令已在本環境（FFmpeg 6.1.1）用測試素材跑過，可正常輸出 1920×1080 H.264 + AAC，中文字卡顯示正常。

### Step 1：照片加 Ken Burns（每張 3 秒）

```bash
ffmpeg -loop 1 -i photo.jpg -vf "scale=3840:-2,zoompan=z='min(zoom+0.0010,1.15)':x='iw/2-(iw/zoom/2)':y='ih/2-(ih/zoom/2)':d=90:s=1920x1080:fps=30,format=yuv420p" -frames:v 90 -c:v libx264 kb_photo.mp4
```

> 先放大到 4K 再 zoompan，可以避免畫面抖動。`d=90` 等於 30fps 下 3 秒。

### Step 2：影片統一規格（混剪前必做）

```bash
ffmpeg -i clip.mp4 -an -vf "scale=1920:1080,fps=30,format=yuv420p" -c:v libx264 v_clip.mp4
```

> 手機直拍影片要改用 `scale=-2:1080,pad=1920:1080:(ow-iw)/2:0`，或做模糊背景填滿。

### Step 3：用 xfade 串接加轉場

```bash
ffmpeg -i kb_1.mp4 -i v_clip.mp4 -i kb_2.mp4 -i kb_3.mp4 -filter_complex \
"[0][1]xfade=transition=fade:duration=0.5:offset=2.5[a];\
 [a][2]xfade=transition=slideleft:duration=0.5:offset=6[b];\
 [b][3]xfade=transition=circleopen:duration=0.5:offset=8.5,format=yuv420p[v]" \
-map "[v]" -c:v libx264 montage.mp4
```

> **offset 計算**：第 n 個轉場的 offset 等於前 n 段長度總和減去 n 個轉場長度。
> 例：3s + 4s 後的轉場 offset = 3 + 4 − 0.5 × 2 = 6。總長 = 各段總和 − 轉場數 × 轉場長度（實測 13 − 1.5 = 11.5 秒）。

### Step 4：加片名字卡＋配樂淡入淡出

```bash
ffmpeg -i montage.mp4 -i music.mp3 -filter_complex \
"[0:v]drawtext=fontfile='/usr/share/fonts/truetype/wqy/wqy-zenhei.ttc':text='2026 社團秋季出遊':fontsize=90:fontcolor=white:borderw=4:bordercolor=black:x=(w-tw)/2:y=h*0.75:enable='between(t,0.3,2.5)':alpha='if(lt(t,0.8),(t-0.3)/0.5,1)'[v];\
 [1:a]atrim=0:11.5,afade=t=in:d=1,afade=t=out:st=9.5:d=2,volume=0.8[a]" \
-map "[v]" -map "[a]" -c:v libx264 -crf 20 -c:a aac -shortest final.mp4
```

> 中文字一定要指定支援中文的 `fontfile`，否則會變成方框。Windows 可用 `C:/Windows/Fonts/msjh.ttc`（微軟正黑體）。

## 7. 輸出版本

| 版本 | 比例／解析度 | 長度 | 用途 |
|---|---|---|---|
| 完整版 | 16:9／1920×1080 | 3–5 分鐘 | YouTube、社團聚會播放 |
| 短影音版 | 9:16／1080×1920 | 30–60 秒 | IG Reels、TikTok、Shorts（只取 Hook＋高潮＋合照） |
| 預告版 | 1:1／1080×1080 | 15 秒 | FB／LINE 社群宣傳下次活動 |

## 8. 做成 Skill 的規格草案

| # | 步驟 | 由誰做 | 輸入 → 輸出 |
|---|---|---|---|
| 1 | 讀素材資料夾、依 EXIF 時間排序、依天數分組 | 腳本 | 照片／影片 → 素材清單 |
| 2 | 挑選與排段落（依第 2 節結構） | Claude（看縮圖） | 素材清單 → 剪輯清單 `edl.csv` |
| 3 | 分析配樂拍點 | 腳本（librosa） | music.mp3 → 拍點時間 |
| 4 | 依拍點分配鏡頭長度、產生 Ken Burns 片段 | 腳本（FFmpeg） | edl.csv → 片段檔 |
| 5 | xfade 串接＋字卡＋配樂 | 腳本（FFmpeg） | 片段 → final.mp4 |
| 6 | 輸出 16:9／9:16／1:1 三版 | 腳本（FFmpeg） | final.mp4 → 三個檔 |
| 7 | 人工檢查節奏、補 NG 花絮 | 使用者 | 預覽 → 修改清單 |

使用者只要提供：**素材資料夾、社團名稱、活動名稱與日期、配樂、感謝名單**。
