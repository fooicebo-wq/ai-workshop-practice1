## 動畫分鏡

| # | 時間 | 畫面 | 技巧 |
|---|------|------|------|
| 1 | 0.2–1.7 秒 | 金線描繪房屋外框和平面格局（屋頂 → 牆 → 隔間、門窗） | SVG 描線動畫（stroke-dashoffset） |
| 2 | 1.8–2.8 秒 | 「集」「思」兩字由模糊浮現 | 逐字錯開（stagger）＋模糊轉清晰 |
| 3 | 2.8–3.8 秒 | 金色光澤掃過品牌字 | 斜向漸層光帶位移 |
| 4 | 3.0–4.4 秒 | 分隔線展開，出現「集思室內裝修企業社」、「空間 · 設計 · 生活」 | 縮放＋淡入 |
| 5 | 3.4–5.8 秒 | 房屋線稿輕微放大縮回，最後淡出 | 呼吸感律動（yoyo） |

## 製作流程（可重複使用）

| # | 步驟 | 指令或說明 |
|---|------|------------|
| 1 | 安裝 | `npm i hyperframes` |
| 2 | 建立專案 | `npx hyperframes init 專案名 --example=blank --non-interactive` |
| 3 | 編寫動畫 | 修改 `index.html`：用 `data-start`／`data-duration` 設定時間，用 GSAP timeline 做動畫 |
| 4 | 檢查 | `npx hyperframes lint`（會抓出會卡頓的寫法） |
| 5 | 輸出 | `npx hyperframes render -q delivery -o 輸出.mp4` |

原始檔放在 `source/` 資料夾，改文字、顏色或時間後重新執行步驟 4、5 即可輸出新影片。

## 測試心得

| 觀察 | 說明 |
|------|------|
| ✅ 可以用 | 在雲端環境約 11 秒就能輸出一支 6 秒的 1080p 影片 |
| ✅ 檢查工具有用 | lint 抓到「字距動畫會卡頓」，改成縮放後就通過 |

## 第二支：集思 Logo 色版輪播（使用正式書法字 Logo）

| 項目 | 內容 |
|------|------|
| 影片檔 | `集思Logo色版輪播.mp4` |
| 規格 | 1920×1080、30fps、12 秒、約 3.4 MB、含背景音樂（AAC 立體聲，約 -15 LUFS） |
| 預覽 | `色版輪播_關鍵影格.png` |
| 原始檔 | `source_色版/`（`gen_palette.py` 會產生 `index.html`，在檔案開頭的色票清單修改顏色；`gen_music.py` 會產生 `bgm.wav`） |
| 影片意義 | 集思室內設計有很多變化、多種色彩，所以畫面上不顯示色名和色碼，只用色點列帶出「多種色彩」 |
| Logo 來源 | 使用者提供的「書法字 LOGO 色版」總覽圖，從黑色版切出 Logo 形狀作為遮罩，所以每個色版都能直接換色 |

### 分鏡（v3：音樂改沉穩、色點圈對齊）

| # | 時間 | 畫面 |
|---|------|------|
| 1 | 0.3–2.0 秒 | 墨綠 Logo 由左往右像毛筆刷出，下方出現色點列（配毛筆刷過的音效和鋪底和弦） |
| 2 | 2.6–9.1 秒 | 依序換色：品牌棕褐 → 鼠尾草綠 → 池水藍 → 薰衣草紫 → 睡蓮粉 → 灰 → 黑，色點圈跟著移動；每次換色都對上一個音符 |
| 3 | 7.6 秒 | 背景轉成墨綠，接著出現白色版、金色版 |
| 4 | 9.7–12 秒 | 金色 Logo 放大縮回，出現「空間 · 設計 · 生活」，配鐘聲收尾，最後淡出 |

### 修改紀錄

| 版本 | 修改內容 |
|------|----------|
| v1 | 色版輪播，顯示色名和色碼 |
| v2 | 加入背景音樂，移除色名和色碼 |
| v3 | 音樂改沉穩；修正色點圈比色點高 6px 的問題（把圈框移進色點列，共用同一個位置）；換色過渡放慢到 0.5 秒 |
| v3-大提琴 | 同 v3 畫面，配樂改成大提琴（`集思Logo色版輪播_大提琴版.mp4`，由 `gen_music_cello.py` 產生 `bgm_cello.wav`）：低音 C 持續音＋和聲大提琴＋旋律大提琴，每次換色一個連弓音，結尾五聲部 C 大和弦 |
| v3-輕爽 | 同 v3 畫面，配樂改成輕爽版（`集思Logo色版輪播_輕爽版.mp4`，由 `gen_music_light.py` 產生 `bgm_light.wav`）：大調 C–G–Am–F，木吉他八分音符分解和弦、清亮鋼琴旋律（每次換色一個音）、輕沙鈴，結尾吉他刷弦＋鐵琴閃光音 |

## 集思影片工作室（總入口）

用瀏覽器打開 `集思影片工作室.html` 就能使用。

| 分頁 | 功能 |
|------|------|
| 製作影片 | 選模板（色版輪播／Logo 開場）、比例（16:9／9:16／1:1）、色版、結尾文字、配樂，即時預覽並可連聲音播放 |
| 作品庫 | 播放已輸出的影片 |
| 功能總覽 | 已實測／可製作待測試／目前做不到 三類功能 |
| 使用說明 | 操作步驟 |

### 輸出流程

| # | 步驟 | 說明 |
|---|------|------|
| 1 | 在頁面調整設定 | 預覽和輸出使用同一份動畫程式 `studio/jisi-video.js` |
| 2 | 按「複製製作指令」 | 貼給 Claude 即可輸出 MP4 |
| 3 | 或按「下載設定檔」 | 在電腦執行 `python3 studio/render_video.py 設定.json 輸出.mp4`（需 Node.js、FFmpeg） |

### studio 資料夾

| 檔案 | 用途 |
|------|------|
| `jisi-video.js` | 影片模板引擎（色版輪播、Logo 開場） |
| `assets.js` | 內嵌 Logo 遮罩與字型，讓頁面直接開啟也能顯示 |
| `render_video.py` | 依設定檔輸出 MP4，會自動下載結尾文字需要的字型 |
| `music/` | 三種配樂：輕爽、沉穩鋼琴、大提琴 |
| `gsap.min.js` | 動畫函式庫 |

- 第一支開場動畫的房屋圖案是示意線稿，不是正式 Logo。
- 色版輪播的 Logo 是從總覽截圖切出來的（原圖寬約 340px，放大 3 倍使用），**邊緣會比原始檔略柔**。如果提供 `logo.png` 原始檔（702×300 透明底），可以換成原始檔再輸出一次，畫質會更清楚。
- 背景音樂是用程式合成的原創配樂，沒有版權問題。v3 改成沉穩版：低音持續音、柔和鋼琴音色、慢速鋪底和弦、較長殘響，換色時每次一個音符（約 83 BPM），結尾是慢慢展開的 C 大和弦。如果想換成指定的音樂，提供音檔即可替換。
- 其他影片提到的工具（Pixel2Motion、Vcraft、Story to Hand-drawn）尚未測試。
