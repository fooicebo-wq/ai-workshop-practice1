| # | 傳送內容 | 說明 |

## 訊息一：開場（複製後修改稱呼）

```
[客人稱呼] 您好，很高興能有機會與您討論新家的規劃！🎉

為了能在初步討論時，為您提供更精準的空間建議與評估，想先請您幫個小忙，向建商（或代銷／工務）索取您這戶的「AutoCAD 原始電子檔（DWG 格式）」。

詳細說明整理在下面這張小卡給您參考👇 通常建商都會免費提供給屋主，過程中有任何問題都歡迎隨時跟我說，我再來協助您！
```

## 訊息二：給建商的話（單獨一則，方便客人轉傳）

```
您好，我是 [X樓之X] 的屋主。因為需要請室內設計師做初步的空間評估，請協助提供本戶的 AutoCAD 圖面電子檔（DWG 格式），煩請包含：建築平面圖、水電弱電圖、消防配置圖，謝謝！
```
